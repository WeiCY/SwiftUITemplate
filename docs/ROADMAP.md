# 路线图

当前主干 Unreleased；已发布版本历史见 [CHANGELOG](../CHANGELOG.md)。规则见 [TEMPLATE_RULES](TEMPLATE_RULES.md)，验证依据见 [ENGINEERING_VALIDATION](ENGINEERING_VALIDATION.md)。

## 本轮已实施

| 阶段 | 实现与验证依据 |
|---|---|
| 运行稳定性 | UIKit 方法隔离；分页失败/重试/竞争；持久化抛错工厂与磁盘迁移；图片取消状态机和实际下载测试；结构化日志脱敏 |
| 接入一致性 | 组合根注入反馈；Alert 存在类型接入；Factory/配置快照恢复；自定义反馈 UI 测试 |
| 宿主与示例 | 本地 Package 的 Xcode App；原生回归/UI 测试；组件目录；表单、搜索分页和媒体组合示例；CI 构建与运行 |
| 品牌与工具 | 统一启动 Token；动态字体；日期、字符串、Codable、重试/超时边界；动画生命周期与减弱动效处理 |
| 文档与工程 | 最短运行入口、迁移说明、关键示例编译检查、测量脚本与当前验证记录 |

保留七个 Library 和可选模块边界，没有新增应用第三方依赖。

## 第二轮已完成

- 五个独立消费者、公开 API 兼容入口、编译/链接边界检查和 iOS 独立宿主进入 CI。
- 分页由宿主状态/统一行为入口驱动，旧 VM 便利适配复用同一 renderer；Network 接入可用 Foundation 配置。
- 全部公开 UI/支撑类型的能力矩阵与目录索引、可复现构建和列表/页面往返内存基线；详细证据见 [MODULE_COMPONENT_REVIEW](MODULE_COMPONENT_REVIEW.md)。
- 最低 iOS18/macOS15 实跑、VoiceOver、真机媒体、iOS 大图解码和长期内存/帧率仍待验收；存在新运行环境或真实 App 时优先补齐。

## 仍需真实宿主验收

- 在真机验证触觉、系统相册/相机授权与拒绝、视频来源差异、真实媒体大文件、后台/前台生命周期。
- 通过 VoiceOver 实际朗读、最大字号和系统减弱动态效果检查所有关键页面；自动化仅覆盖部分流程。
- 网络 App 接真实后端验收认证、分页排序、服务端错误及隐私日志；默认 Mock 不能替代后端契约验证。
- 在生产数据库副本上验证宿主自己的迁移计划；示例的可选字段迁移不能代表所有模型升级。
- 用一个离线 App 和一个网络 App 走完真机、TestFlight 及发布流程，本轮不提交、推送或发布。

## 后续按需求推进

| 方向 | 触发条件 / 验收标准 |
|---|---|
| 运行时品牌切换 | 多个宿主有稳定换肤需求后，补可观察注入及刷新保证；当前仅启动配置 |
| 图片平台图像接口 | 证明 Data 协议额外解码影响后，设计兼容的可选平台图像能力和 iOS 基准 |
| 更完整的可访问性 UI 矩阵 | 有运行预算后覆盖系统设置、页面返回和后台恢复 |
| OSLog subsystem/category 配置 | 宿主确有统一可观测性需求时扩展配置 |
| 发布和多 App 版本治理 | 复制升级成为实际瓶颈时再引入自动化 |
| 游标分页、复杂主题包、其他平台 | 有多个真实需求后再评估，避免 Core 膨胀 |

新增能力仍遵循局部修复、协议与初始化注入优先。发布由维护者主动执行，完成测试不代表自动发布。
